# Boutique de Miel APIGOLD

## Description
Ce projet est un site web pour la boutique de miel APIGOLD. Il permet aux utilisateurs de parcourir les produits, de se connecter, d'ajouter des articles au panier et de passer des commandes.
et meme le moderateur de la boutique a son interface personnelle afin d y acceder et ajouter,modifier,supprimer des produits.

## Fonctionnalités
- **Page d'accueil** : Présentation des produits et de la boutique.
- **Page de connexion** : Authentification des utilisateurs (clients et administrateurs).
- **Panier d'achat** : Gestion des articles sélectionnés.
- **Validation de commande** : Passage de commande avec calcul du total.
- **INTERFACE ADMIN** : gerer les produits de la cooperative (ajouter,modifier,supprimer).

## Technologies utilisées
- **Frontend** : HTML, CSS, JavaScript
- **Backend** : JEE (JSP, Servlets)
- **Base de données** : MySQL
- **Hébergement** : GitHub Pages
